# Manas Chimakurthi — Portfolio

A responsive React + Vite portfolio using a charcoal and orange visual theme.

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Production build
Run `npm run build`. The deployable site is generated in `dist/`.

## Personalize later
- Add project URLs when available.
- Add a resume link or downloadable PDF when ready.
- Add a profile photo if desired.
- Add GitHub when a profile is available.

The project summaries are intentionally high-level because detailed descriptions and project links were not supplied.
